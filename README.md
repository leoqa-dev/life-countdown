# life-countdown

## 项目简介

人生倒计时是一个基于 Vite 构建的静态网页应用，通过可视化的方式展示人生剩余时间倒计时，提醒使用者珍惜时间。

## 在线体验

可通过 GitHub Pages 访问：https://leoqa-dev.github.io/life-countdown/

## 技术栈

该项目使用 Vite 进行构建打包，仓库默认分支为 gh-pages，保存的是已构建生成的静态产物（HTML、JS、CSS），并直接通过 GitHub Pages 部署上线。

## 说明

该仓库主要存放构建后的部署产物；同主题的浏览器插件版本可参考仓库 TheEnd-Plugin。
